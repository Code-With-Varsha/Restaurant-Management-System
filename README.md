# Restaurant Management System

A simple Restaurant Management System developed using Python and MySQL.

## Technologies Used

- Python
- MySQL

## Project Description

This project is designed to manage basic restaurant operations such as menu items, customer details, and orders.

## Database Tables

- Menu Items
- Customers
- Orders

## Features

- Manage restaurant menu items
- Store customer information
- Manage customer orders
- Store order quantity and total amount
- Maintain order date and time

## Project Files

- `restaurant_management.py` – Python program
- `database.sql` – MySQL database and table queries
